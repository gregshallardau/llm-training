Module 00

Think of It as a Brain

🧠 A brilliant new colleague on their permanent first day: vast knowledge, zero memory of you.

The one analogy

The LLM is a brilliant new colleague on their permanent first day. They have read everything ever written and write at extraordinary speed — and they have zero memory of you, your clients, or what you did yesterday.

Every conversation is day one. Your job is to write the onboarding note that makes day one productive.

The transformer implements functional analogues of cognition: chunked perception (tokenisation), selective attention (self-attention), a bounded working memory (context window) and sequential production (autoregressive decoding).

What's missing is episodic memory — there is no cross-session persistence. The base layer is an external memory prosthetic for that gap.

Attention approximates selective-attention models (Treisman 1964; Posner 1980); the context window behaves as a bounded working memory (cf. Cowan's 4±1). With no inference-time plasticity, the model forms no new associations within a session — it only leverages associations learned in training.

In-context conditioning substitutes an external episodic memory for the missing internal mechanism.

Module 03

The Attention Mechanism

🎛️ A mixing desk deciding how loud each word is in the mix.

What attention does

When you read a long file your eyes don't weight every word equally — you link "the client" to the name at the top of the page.

Attention is the model asking, for every word: which other words matter to me right now? — then focusing there.

Scaled dot-product attention: each token emits query / key / value vectors; weights are softmax(QKᵀ/√d) over the keys, and the output is a weighted sum of values.

Multiple heads learn different relations — syntax, coreference, position — in parallel.

Self-attention is content-based addressing over the sequence; causal masking makes decoding autoregressive.

Because position 0 is attendable by every later token, the system prompt exerts maximal influence — a structural reason base layers work so well.

Module 08 ⭐

The Base Layer

📋 The onboarding document you hand the AI every single conversation.

Teaching the AI who you are

The base layer tells the AI who it's helping — your role, your clients, your style — so you stop re-explaining yourself and every answer comes back sharper and more like you.

A reusable context prefix injected ahead of the task. It converts your private knowledge into in-context information, compensating for the lack of persistent memory. Written once, pasted per session or pinned via custom instructions.

In-context conditioning shifts P(response | task) toward your distribution with no weight updates — retrieval-free personalisation, the highest-leverage intervention available without fine-tuning.

Six questions the base layer answers

WHO

Your role, team, clients.

WHAT

Daily work, standards.

WHERE

Industry, location.

WHEN

Rhythms, deadlines.

WHY

Goals, values.

HOW

Communication style.
