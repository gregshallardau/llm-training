The Three Context Levels

Raw vs dump vs distilled

Level 1: Raw Prompt

"Write a summary report on the Henderson project."

Generic template. Placeholder text. [Project Name].

Result: Generic, useless

Level 2: Document Dump

Paste project plan, emails, budget, meeting notes.

Real names, dates, numbers. But disorganised and redundant.

Result: Better but messy

Level 3: Distilled Prompt

Base layer + key facts + clear brief.

Tailored, prioritised, audience-aware.

Result: Professional output

Context Quality Spectrum

No Context → Generic Output
Document Dump → Messy but Real
Distilled → Professional Output

Raw Prompt

New person, never met you, knows nothing

Document Dump

Access to filing cabinet, but no context on what matters

Distilled

Briefed colleague: knows who you are, what matters, who's reading

🎯 Why Distilled Works Better

With O(n²) attention complexity, more tokens = more dilution. Important info gets buried in a long context. Distilled prompts use fewer tokens = stronger signal. Key info stands out. Less noise, stronger signal.
