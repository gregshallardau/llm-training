The one shift everything hangs on

A normal user asks: "How do I do this task?"
A power user asks: "What kind of problem is this — and what system handles that kind?"

Normal users do the work. Power users direct the work. The tools will change — models, apps, features — but the reflex won't. Someone who asks "what kind of problem is this?" stays a power user through every tool that comes next.
